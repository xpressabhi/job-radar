# job-radar

Daily, GitHub-Actions-powered crawl of **senior+ engineering roles in India** (or remote-India)
at companies **vetted to pay top-of-market**: ≥₹20L base generally, ≥₹50L base at senior levels.

Outputs: a static filterable page, an archive of closed roles, and `jobs.json` / `feed.xml`
feeds. Zero runtime dependencies, zero secrets.

- Implementation plan: `tasks/plan.md` · task list: `tasks/todo.md`
